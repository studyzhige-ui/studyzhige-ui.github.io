# Blog posts

这个目录就是博客文章的“内容库”。

## 新建文章

文件名必须是：

`YYYY-MM-DD-title.md`

例如：

`2026-08-20-my-first-post.md`

文件内容示例：

```markdown
---
title: 我的第一篇文章
description: 一句话摘要，可选
tags: [AI, 随笔]
---

从这里开始写正文。
```

提交到 `main` 后，GitHub Pages 会自动把文章加入 `/blog.html`。

## 修改文章

直接编辑对应的 `.md` 文件并提交。

## 删除文章

删除对应的 `.md` 文件并提交。部署完成后，文章会从博客列表中消失。
